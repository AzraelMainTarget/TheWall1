# Cloudflare с телефона: пошагово по твоему меню

Это дополнение к `CLOUDFLARE-START.md` — с учётом того, что видно у тебя на экране.
Автор: NeWerMoRe

---

## Почему нет «Workers create»

В новом дашборде Workers убрали с главного меню.
Они теперь внутри раздела **Compute**.

На твоём скриншоте это пункт с иконкой `<>` и словом **Compute** —
четвёртый сверху, под заголовком «Build».

---

## Путь №1: через меню (3 нажатия)

1. **Compute** — иконка `<>`, под словом «Build»
2. Внутри найди **Workers & Pages**
3. Кнопка **Create** (сверху справа) → **Start with Hello World!** → **Deploy**

---

## Путь №2: по прямой ссылке (быстрее, если меню путает)

Вставь в адресную строку браузера:

```
https://dash.cloudflare.com/?to=/:account/workers-and-pages
```

Откроется сразу список воркеров, минуя меню.
Дальше: **Create** → **Start with Hello World!** → **Deploy**.

**Этот путь надёжнее на телефоне.** Если меню где-то схлопнулось или пункт
не показывается — прямая ссылка всё равно приведёт куда нужно.

---

## Что делать в редакторе

После **Deploy** откроется страница воркера:

1. Нажми **Edit code** (или «Continue to project» → **Edit code**)
2. Слева будет файл `worker.js` с кодом-заглушкой
3. Выдели **весь** код внутри файла и удали
4. Вставь всё содержимое `engine/worker-single.js` из нашего репозитория
5. **Deploy** (кнопка справа сверху)

---

## Где взять адрес

После деплоя на странице воркера будет строка вида:

```
https://ragnell-engine.твой-ник.workers.dev
```

**Пришли мне только её.** Пароль не нужен, токен не нужен — на этом шаге
достаточно одного адреса, чтобы проверить, что воркер живой.

---

## Проверка

Открой в браузере:

```
https://ragnell-engine.твой-ник.workers.dev/api/health
```

Ждём ответ:

```json
{ "ok": true, "author": "NeWerMoRe", "backend": "cloudflare", "storage": "none" }
```

`"storage": "none"` — это нормально на этом шаге: R2 ещё не подключён.

---

## Если что-то пошло не так

| Что видишь | Что значит |
|---|---|
| `401 unauthorized` | воркер работает, просто нужен ключ — это хороший знак |
| `Cannot use import statement` | вставился старый `worker.js`, нужен именно `worker-single.js` |
| Пустая страница | деплой не прошёл, нажми Deploy ещё раз |
| Пункта Compute нет вовсе | используй Путь №2, прямую ссылку |

---

## После воркера — R2

Не сейчас. Сначала убедимся, что воркер отвечает.
Затем: **Storage & databases** (в твоём меню, под «Build») → **R2** → создать бакет.
