## Куда нажать

Смотри на свой экран:

```
[ Overview ]  [ Metrics ]  [ Deployments ]  [ Observabi... ]     [ ... ]
```

Три варианта, любой подойдёт:

### Вариант 1 — самое короткое

Внизу страницы, снизу справа, есть кнопка **`</>`** (иконка «код»)
или пункт **Edit code**.

Нажми → откроется редактор.

### Вариант 2 — через меню

Сверху справа три точки **`⋯`** → **Edit code**

### Вариант 3 — прямая ссылка

Если кнопок не видно, вбей в адресную строку:

```
https://dash.cloudflare.com/?to=/:account/workers-and-pages
```

Откроется список воркеров → нажми на **`r`** → **Edit code**

---

## Что делать в редакторе

1. Слева увидишь файл — обычно `worker.js`
2. Нажми на него
3. Выдели **весь** код (долгое нажатие → «Выделить всё»)
4. Удали
5. Вставь **весь** файл `engine/worker-single.js` из нашего репозитория
6. Справа сверху — **Deploy**

## Если редактор не открывается на телефоне

Так бывает: панель кода на узком экране иногда схлопывается.
Тогда вариант с токеном (он в `CLOUDFLARE-START.md`, вариант Б) — я задеплою сам.

Токен создаётся там:
аватар справа сверху → **My Profile** → **API Tokens** → **Create Custom Token**
Права: `Workers Scripts: Edit`, `Workers R2 Storage: Edit`, `Account Settings: Read`
