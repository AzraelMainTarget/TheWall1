# Modal: что сделать тебе, что сделаю я

## Тебе — 4 команды

```bash
pip install modal
modal token new                    # откроет браузер → войдёшь в свой аккаунт
modal secret create hf-token HF_TOKEN=hf_xxx    # токен с huggingface.co/settings/tokens
modal deploy engine/modal_ltx.py
```

Последняя команда напечатает адрес вида:

```
https://<твой-юзер>--ragnell-ltx-generate.modal.run
```

**Скопируй его и пришли мне.** Дальше всё делаю я.

## Что сделаю я

1. Вставлю адрес в `env.GPU_URL` воркера
2. Прогоню первый запрос и проверю, что клип приходит
3. Соберу сквозной путь: браузер → воркер → Modal → R2 → плеер
4. Покажу тебе первый настоящий клип от модели

## Что я исправил в скрипте (по свежей документации)

| Было | Стало | Почему |
|---|---|---|
| `LTXPipeline` | `LTX2Pipeline` | LTXPipeline был у LTX-Video 0.9, не у LTX-2 |
| `torch_dtype=` | `dtype=` | в diffusers 2026 переименовали |
| `Lightricks/LTX-Video` | `Lightricks/LTX-2.5-Diffusers` | актуальные веса |
| обычные шаги | `sigmas=DISTILLED_SIGMA_VALUES` | быстрый путь, 8 шагов вместо 30 |
| видео | `(video, audio)` + `encode_video` | LTX-2 отдаёт ещё и звук |

Если бы я отдал старую версию — ты получил бы ошибку импорта на первой же минуте.

## Сколько это стоит

A100-80GB — $2.50/час. Бесплатные $30 = **12 часов GPU**.
Один клип 121 кадр ≈ 3–5 минут → **150–200 клипов бесплатно**.
Простой не тратит: через 2 минуты GPU отпускается.

## Если A100 не даст Modal

Запасной путь: `gpu="L40S"` (48 ГБ) + квантование fp8.
Впиши в `@app.cls(...)`, остальное без изменений.
