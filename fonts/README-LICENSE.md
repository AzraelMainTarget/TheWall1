# Шрифт в этом каталоге

**blackletter-extrabold.woff2**
Blackletter ExtraBold — (c) Typographer Mediengestaltung, 2001.
Источник: dafont.com («Amano» / Blackletter DS).

## Лицензия — ВАЖНО

Шрифт распространяется как **«Free for personal use»** — только для
личного, некоммерческого использования.

Если проект станет коммерческим (продажи, реклама, платные продукты
под брендом Project Gate / That Darkness), шрифт нужно **заменить на
купленный** или **перерисовать буквы вручную** как векторные формы.

Ничего другого в проекте этот файл не затрагивает: убрать его —
значит убрать один `@font-face` в `index.html` и одну строку в
`fonts/`.
