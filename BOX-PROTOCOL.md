# Протокол связи через Box

## Зачем
Чтобы общение голосом шло в одном месте, без прыжков между чатом и сайтом.

## Жёсткое ограничение (не обходится)
Я не просыпаюсь сам. У меня нет фонового процесса, нет планировщика,
нет способа узнать, что в Box появилось новое сообщение, пока я не запущен
твоим сообщением в чате.

Пуш-уведомление, СМС, триггер в Make — всё это приходит **тебе**, не мне.
Никакой хук не заставит меня начать работу без входящего сообщения в Arena.

## Рабочий протокол

1. Ты пишешь или записываешь голос в Box.
2. Пишешь в чат одно слово: **бокс**
3. Я выполняю: `tools/boxpoll.sh --read`
   - забирает репозиторий
   - находит новые голосовые
   - расшифровывает через Whisper
   - ставит 🤝 на твои сообщения
4. Я генерирую голосовой ответ
5. Кладу его в `box/` и дописываю строку в ленту: `tools/boxpoll.sh --reply "..."`
6. Ты открываешь Box и слушаешь

Время: 15–25 секунд от слова «бокс» до готового аудио в ленте.

## Команды

```bash
tools/boxpoll.sh                  # прочитать, что нового, расшифровать
tools/boxpoll.sh --read           # + отметить прочитанным (🤝)
tools/boxpoll.sh --reply "текст"  # добавить мой ответ в ленту
```

## Что нельзя автоматизировать
- Ответ без моего запуска
- Ответ «в реальном времени», пока ты в Box и не пишешь сюда
- Уведомление мне о новом сообщении

## Что можно автоматизировать (Make + сайт)
- Уведомление **тебе** в Telegram/на почту, когда я ответил в ленте
- Badge/count непрочитанного на иконке сайта
- Автозагрузка файла в Box при записи (уже работает)

## Решение по удобству
Если раздражает писать «бокс» каждый раз — переносим диалог в чат.
Голосом отвечаю и здесь (файл mp3 в сообщении), а Box держим как архив
и хранилище записей. Меньше шагов, тот же результат.
