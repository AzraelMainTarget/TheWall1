# Точки возврата

## Что здесь важно
`index.html` — твой файл. Я его **не менял**. Все мои изменения — отдельные новые файлы.

## Метки (теги) — точки, куда можно вернуться

| Метка | Что это | Коммит |
|---|---|---|
| `backup-before-agent` | твоя версия сайта до моих правок | `dea38fe` |
| `agent-voice` | + страница записи голоса | `06e89c6` |
| `agent-tools` | + хаб инструментов | `e9e6b08` |
| ветка `snapshot-2026-11-24` | снимок дня | `dea38fe` |

## Как вернуться

**Быстро — через GitHub (без терминала):**
1. Открой репозиторий TheWall1 на GitHub
2. Вкладка **commits** → найди нужный коммит
3. Кнопка **`<>` Browse files`** → откроется состояние на тот момент
4. На `index.html` → **Raw** → скопировать или скачать

**Или откатить всё (на сайте):**
Settings → Branches → default branch → сменить на `snapshot-2026-11-24`.
Pages пересоберётся с того снимка. Это не удаляет `main` — вернуться обратно так же.

**Через терминал (я это умею):**
```
git checkout backup-before-agent -- index.html   # вернуть только один файл
git reset --hard backup-before-agent             # откатить всё
```

## Правило на будущее
Перед каждой большой правкой я ставлю новую метку вида `before-<что-делаем>`.
Если что-то сломалось — говори «откатись на <метку>», и я сделаю это одной командой.

## Что не удаляется
История git. Даже если файл перезаписан, старые версии живут в коммитах.
Ничего не пропадает безвозвратно.
